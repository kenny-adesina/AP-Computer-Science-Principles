# What Computer Science?

<p>Computer Science is the study of computers and how they utilize information. Basically, how computers work.</p>

<p>Computer Science is important because computers are <i>everywhere</i>, so it is really useful to learn how they use inputs to generate the outputs that you see on your screen!</p>

<p>What exactly <i>is</i> a computer though? It's actually pretty simple! A <b>computer</b> is an <b>electronic device</b> that stores and processes information.</p>

<p>Let's think of some examples.</p>
